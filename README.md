# SkillNotes – Сервис личных заметок на Node.js

Веб-приложение для управления персональными заметками с поддержкой Markdown.

## Установка и запуск

```bash
npm install
cp .env-sample .env
npm start
```

## Доступные команды

- npm run build – сборка фронтенда
- npm start – запуск приложения (с миграциями БД)
- npm run db:migrate – применение миграций базы данных

## Тестовый пользователь

После первого запуска создаётся пользователь:

- Email: asdf
- Пароль: asdf

## Функциональность

- Регистрация и вход
- Создание, редактирование, удаление заметок
- Поддержка Markdown
- Архивация и разархивация
- Фильтрация по датам (неделя, месяц, 3 месяца, всё время, архив)
- Постраничная загрузка заметок

## Технологии

- Node.js, Express
- PostgreSQL, Knex.js
- Svelte (фронтенд)
- Nunjucks (шаблоны)
- Markdown (отображение заметок)
